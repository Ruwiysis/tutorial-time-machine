Linear Regression from Scratch in TensorFlow

Before reaching for Keras, it's worth understanding how TensorFlow really works: you build a computation graph, then run it inside a session. Let's fit a line to some noisy data.

1. Generate data

NumPy is all we need for fake data:

import numpy as np

x_data = np.random.rand(100).astype(np.float32)
y_data = 3.0 * x_data + 2.0 + np.random.normal(0, 0.1, 100)

2. Build the graph

Placeholders are where we feed data in; Variables are what we learn:

import tensorflow as tf

X = tf.placeholder(tf.float32, name="X")
Y = tf.placeholder(tf.float32, name="Y")

W = tf.Variable(0.0, name="weight")
b = tf.Variable(0.0, name="bias")

prediction = W * X + b
loss = tf.reduce_mean(tf.square(prediction - Y))

optimizer = tf.train.GradientDescentOptimizer(learning_rate=0.5)
train_op = optimizer.minimize(loss)

3. Train in a session

init = tf.global_variables_initializer()

with tf.Session() as sess:
    sess.run(init)
    for step in range(200):
        sess.run(train_op, feed_dict={X: x_data, Y: y_data})
        if step % 50 == 0:
            print(step, sess.run([W, b]))

After a couple hundred steps, W lands near 3 and b near 2. You just trained a model the low-level way!
