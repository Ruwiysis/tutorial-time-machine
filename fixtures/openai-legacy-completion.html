Summarize Any Article with GPT-3 and Python

Large language models are great at summarizing. In this quick tutorial we'll write a Python script that reads a text file and asks GPT-3 for a three-bullet summary.

1. Install the library and set your key

pip install openai==0.27.0
export OPENAI_API_KEY="sk-..."

2. The script

import os
import sys
import openai

openai.api_key = os.getenv("OPENAI_API_KEY")


def summarize(text):
    prompt = f"Summarize the following article in three bullet points:\n\n{text}\n\nSummary:"
    response = openai.Completion.create(
        engine="text-davinci-003",
        prompt=prompt,
        max_tokens=200,
        temperature=0.3,
    )
    return response["choices"][0]["text"].strip()


if __name__ == "__main__":
    with open(sys.argv[1], encoding="utf-8") as f:
        article = f.read()
    print(summarize(article))

3. Handle errors

The API can rate-limit you. Catch the error and retry after a pause:

import time

try:
    print(summarize(article))
except openai.error.RateLimitError:
    time.sleep(20)
    print(summarize(article))

Run it with python summarize.py article.txt. Enjoy your instant TL;DR!
