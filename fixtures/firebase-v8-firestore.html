Build a Realtime Chat with Firebase and Cloud Firestore in 15 Minutes

Firebase makes realtime apps ridiculously easy. In this tutorial we'll build a tiny chat room with Cloud Firestore for storage and anonymous Firebase Authentication, all from plain JavaScript in the browser. No server required!

1. Install and initialize Firebase

Install the SDK from npm, then paste your project config from the Firebase console:

npm install firebase@8.10.0
import firebase from 'firebase/app';
import 'firebase/auth';
import 'firebase/firestore';

const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'your-app.firebaseapp.com',
  projectId: 'your-app',
};

firebase.initializeApp(firebaseConfig);

const db = firebase.firestore();
const auth = firebase.auth();

2. Sign users in anonymously

We don't want a sign-up form for a demo, so every visitor gets an anonymous account:

auth.signInAnonymously().catch((error) => {
  console.error('Sign-in failed', error);
});

auth.onAuthStateChanged((user) => {
  if (user) {
    console.log('Signed in as', user.uid);
  }
});

3. Send a message

Each message is a document in the messages collection. We use a server timestamp so messages sort correctly no matter whose clock is wrong:

async function sendMessage(text) {
  const trimmed = text.trim();
  if (!trimmed) return;

  await db.collection('messages').add({
    text: trimmed,
    uid: auth.currentUser.uid,
    createdAt: firebase.firestore.FieldValue.serverTimestamp(),
  });
}

4. Listen for new messages in realtime

This is the magic part. onSnapshot fires every time the query results change:

const list = document.querySelector('#messages');

db.collection('messages')
  .orderBy('createdAt')
  .limit(50)
  .onSnapshot((snapshot) => {
    list.innerHTML = '';
    snapshot.forEach((doc) => {
      const li = document.createElement('li');
      li.textContent = doc.data().text;
      list.appendChild(li);
    });
  });

5. Lock it down

Finally, don't forget security rules. Only signed-in users may write, and nobody may edit other people's messages:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /messages/{id} {
      allow read: if true;
      allow create: if request.auth != null
                    && request.resource.data.uid == request.auth.uid;
    }
  }
}

That's it! Deploy with firebase deploy and share the link with a friend. 🎉
