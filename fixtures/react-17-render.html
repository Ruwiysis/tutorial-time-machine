React for Beginners: Your First Counter App

New to React? Let's build the classic counter. You'll learn components, state with hooks, and how to mount your app into the page.

1. Set up the project

npx create-react-app my-counter
cd my-counter
npm start

2. Write the component

Hooks let function components hold state. useState returns the current value and a setter:

import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div className="counter">
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>Click me</button>
    </div>
  );
}

export default Counter;

3. Mount it

In src/index.js, render the component into the root div from public/index.html:

import React from 'react';
import ReactDOM from 'react-dom';
import Counter from './Counter';

ReactDOM.render(
  <React.StrictMode>
    <Counter />
  </React.StrictMode>,
  document.getElementById('root')
);

4. Bonus: hydrate server-rendered HTML

If your HTML was rendered on the server, attach React to it instead of re-rendering:

ReactDOM.hydrate(<Counter />, document.getElementById('root'));

Save, and your browser reloads with a working counter. Congratulations on your first React app!
